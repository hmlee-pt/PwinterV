# 運動員防受傷檢測系統 (Athletic Mobility & FMS Screening PWA)

> **目前版本 (Current Version)**: `v1.0.2`  
> **最後更新日期**: 2026-11-20  
> **軟體形態**: Mobile Web / PWA (漸進式網頁應用，支援手機端離線使用與安裝至桌面)

---

## 📌 系統簡介

本系統是一套專為運動員、教練、物理治療師與運動愛好者打造的**手機端 AI 關節活動度與防受傷檢測軟體**。
由施測者（教練、訓練員或家長）手持手機，運用手機相機與端側 Google MediaPipe Pose 電腦視覺骨架追蹤，即時評估運動員下肢活動度 (ROM)、代償動作以及**左右不對稱性 (Left-Right Asymmetry)**，即時預警運動受傷風險並提供客製化伸展處方。

---

## 🚀 核心功能特色

1. **施測者手持專用 HUD 與電子水平儀 (Digital Bubble Level)**：
   - 頂部整合手機陀螺儀水平儀（綠/黃/紅狀態燈），協助施測者手持時保持平視垂直地面，消除透視俯仰角誤差。
   - 畫面即時繪製 33 點 3D 骨骼連線與目標髖關節量角弧形。
2. **ASLR (主動直膝抬腿) 專業活動度量測**：
   - 即時計算腿部與水平線/軀幹夾角（正常標竿 $\ge 75^\circ$）。
   - **防代償機制**：即時監測抬起腿膝蓋是否打直 ($\ge 155^\circ$)、對側支撐腿是否平貼地面 ($\ge 160^\circ$)。
3. **雙鎖定取樣機制**：
   - **自動停頓鎖定**：受測者抬腿至極限維持 1.5 秒自動鎖定峰值。
   - **手動快門鎖定**：施測者可隨時點擊「📸 鎖定」按鈕手動打點。
4. **受傷風險評估與客製伸展處方**：
   - 自動比對左右兩側活動度差值 (Asymmetry Ratio)。
   - 當單側 $<60^\circ$ 或左右差 $>15\%$，即刻觸發「🚨 高度受傷風險警示」，預防衝刺跑者大腿後肌撕裂。
   - 提供針對緊繃側的滾筒筋膜放鬆與坐姿神經滑動術指引。
5. **雙語音引導與音訊反饋**：
   - 內建繁體中文 TTS 語音廣播（「請抬起右腿」、「右腿完成，請換左腿」）與鎖定成功雙頻提示音。
6. **零雲端上傳 (100% 隱私保護)**：
   - 影像完全在手機瀏覽器內部 WebAssembly/WebGL 記憶體中運算，絕不上傳任何伺服器。
7. **PWA 支援與離線運行**：
   - 支援手機瀏覽器「加入主畫面」，無網路/飛航模式下仍可開啟並啟動相機檢測。
8. **免真人模擬展示 (Demo Simulation Mode)**：
   - 點擊「🎮 模擬展示」即可預覽完整雙腿抬起、停頓鎖定與受傷評估流程。

## 🛠️ 快速啟動與本機測試

### 1. 安裝相依套件
```bash
npm install
```

### 2. 啟動開發伺服器 (支援手機同 Wi-Fi 連線)
```bash
npm run dev
```
啟動後終端機會顯示本地網址（例：`http://localhost:3000`）與區域網路網址（例：`http://192.168.1.xxx:3000`）。施測者手機連接相同 Wi-Fi 即可直接以手機瀏覽器開啟測試。

### 3. 建置生產環境靜態檔案
```bash
npm run build
```
建置輸出將產生於 `dist/` 目錄，可直接上傳至 **GitHub Pages**、**Vercel** 或任何靜態 HTTPS 託管服務。

### 4. 執行單元測試
```bash
npm test
```

## 🔄 歷史版本切換與回溯指引

為確保版本可回溯性，專案提供 Git 實體標籤快照與一鍵切換工具：

### 方法一：Windows 一鍵批次切換工具 (推薦)
雙擊執行專案根目錄的 `切換版本.bat`，即可透過選單檢視所有標籤並一鍵切換版本。

### 方法二：Git 指令操作
```bash
# 1. 檢視所有歷史版本
git tag -l

# 2. 切換至指定歷史版本 (檢視與驗證模式)
git checkout v1.0.0

# 3. 切回最新開發主線
git checkout master   # 或 git checkout main

# 4. 以歷史版本為基底展開新修復分支
git checkout -b restore-v1.0.0 v1.0.0
```
